# research/papers

Original PDFs for the papers referenced in `../references.md` **should normally not be committed**.

**Policy:**

- Keep citations, DOIs, and URLs in [`../references.md`](../references.md) and [`../sources.md`](../sources.md).
- Only commit a paper PDF here if its license explicitly permits redistribution (e.g. CC-BY). For most Elsevier/Springer/IEEE publications that is **not** the case.
- If a teammate needs a specific paper for reading, share it out-of-band (e.g. private Drive) and reference it here by filename + DOI only, e.g.:

```text
02_senanayake_rockfall_ml.pdf   → 10.1016/j.ijrmms.2024.105727 (shared privately, not committed)
```

See `../references.md` for the "why it matters / what Talus takes from it / what it is NOT used for" notes per paper.
